# Implementation Plan: 同步任务多项优化

**Branch**: `013-sync-optimizations` | **Date**: 2026-01-16 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/013-sync-optimizations/spec.md`

## Summary

本功能包含 7 个独立的优化项，旨在提升同步任务的用户体验和系统可靠性：
1. **任务完成 Toast 提醒** (P1) - 同步完成后全局通知用户
2. **传输进度区分上传/下载** (P1) - 在传输列表中显示方向图标
3. **显示检查中的文件数** (P2) - 实时展示扫描进度
4. **允许禁用任务** (P2) - 任务启用/禁用状态管理
5. **空任务清理优化** (P3) - 滚动替换逻辑，保留最新空记录
6. **缓存数据库大小修复** (P3) - 包含 WAL/SHM 文件的完整大小
7. **概览卡片数据分离加载** (P2) - 解决远程 Quota 加载阻塞本地缓存状态显示的问题
